# GTA RP — official player downloads

[Download the Windows launcher](https://github.com/VisibleNumber/sa-rs-roleplay/releases/latest/download/GTA-RP-Launcher.zip)

1. Extract the launcher ZIP into a writable folder.
2. Double-click **Launch GTA RP.cmd**.
3. The installer downloads and verifies the signed player client.
4. Select your own GTA San Andreas installation if prompted.
5. Register a launcher account and create your server character in game.

No Rust installation is needed. GTA San Andreas game data is not included.
